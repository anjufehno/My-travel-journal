# My Travel Journal

> **Learning project** · Data-driven React interface.

A small travel journal application that renders destination entries from structured local data using reusable React components.

## Features

- Reusable travel-entry component
- Data-driven rendering with `map()`
- Component props
- Structured local content
- Responsive card-style layout

## Tech Stack

`React` · `JavaScript` · `CSS`

## What I Practised

- rendering collections in React
- passing structured data through props
- keeping data separate from presentation components
- reusable component composition

## Run Locally

```bash
git clone https://github.com/anjufehno/My-travel-journal.git
cd My-travel-journal
npm install
npm start
```
